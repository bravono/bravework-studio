# Turnkey Lesson Plan Specification & Template

This document provides the mandatory structural standard for lesson scripts generated by the Course Architect Agent. Generic high-level outlines are strictly prohibited. Every lesson must be fully turnkey and actionable down to the minute.

---

## Canonical Lesson Block Template

Each module must be divided into concrete chronological blocks (typically 10 to 25 minutes each). Each block must use the following schema:

```markdown
### Block [Number]: [Block Title]
- **Time Allocation**: [HH:MM - HH:MM] ([Duration] Minutes)
- **Slide / Focal Concept**: [Slide Title or Screen Asset Name]

#### 1. Teacher Script & Framing
[Verbatim talking points for the instructor. Explains the "why", conceptual mental model, and pedagogical framing without filler.]

#### 2. Exact On-Screen Actions
- [Cursor / Tool Navigation]: Navigate to Top Menu > Tools > [Tool Name].
- [Hotkey / Shortcut]: Press [Key Combination] to activate [Mode].
- [Parameter Values]: In the Properties Inspector, set:
  - Property A: [Exact Value / Unit]
  - Property B: [Exact Value / Unit]
- [Viewport Execution]: Click and drag from coordinate (X1, Y1) to (X2, Y2).

#### 3. Student Hands-On Checkpoint
- **Objective State**: What the student viewport or workspace must look like.
- **Verification Rule**: "The student screen must show [Specific Geometry / Component] with [Specific Status] visible in the outliner."
- **Self-Test Step**: Student presses [Key] or runs [Command] to verify output matches reference.

#### 4. Pitfalls & Troubleshooting
- **Error Condition**: [Common student mistake or warning message].
  - **Root Cause**: [Explanation of why this occurs].
  - **Immediate Fix**: [Step-by-step resolution steps].
```

## Live Checkpoint vs. Recorded Lesson Video Plan Adaptation

When adapting a curriculum between Live Cohort and Pre-Recorded Video plans:

| Structural Element | Live Cohort Delivery | Asynchronous Recorded Delivery |
| :--- | :--- | :--- |
| **Pacing Cue** | "Instructors pause and request typed 'Ready' confirmations in chat." | "On-screen pause banner: 'PAUSE NOW: Complete Exercise 2.1 (Est. 15 min)'." |
| **Checkpoint Verification** | Live breakout room check or screen-share verification by teaching assistant. | Self-check comparison with downloadable reference state file (`checkpoint_02_01.ext`). |
| **On-Screen Framing** | Live camera overlay + active monitor screen share with live Q&A intervals. | Tight focus capture, magnified shortcut callouts, and chapter markers in timeline. |
| **Troubleshooting Delivery** | Real-time audio intervention addressing live student blockers. | Dedicated "If your screen looks like this..." diagnostic screen overlay. |
